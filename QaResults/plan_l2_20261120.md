# L2（戻る先を LLM が選ぶ）本番比較の計画 — 2026-11-20、実行前に記録

## 目的
同じ8候補から戻る先を選ぶとき、LLM（詳しい説明つき）が、LLM を使わないルールより多く・早くバグを見つけるかを調べる。

## 条件（実行後に変更しない）
- 手法（すべて Position+Keys、候補数 k=8）
  - `GoExplore` … 元の訪問回数ルール
  - `UniformGoExplore` … 8候補からでたらめに選ぶ
  - `UnvisitedGoExplore` … 8候補から「近くの未訪問マス（6歩以内）」が最多のものを選ぶ（LLM なし）
  - `LlmGoExplore` … 8候補から LLM が選ぶ（`--llm-describe rich`）
- モデル: qwen2.5:7b-instruct（temperature=0, seed=0）
- 予算: 2,000 ステップ、シード 0〜9（10本）、バグは全部有効（`--mode all`）

## 評価
- 主指標: 検出の AUC（`analysis/plot_curves.py` の `summary_agents.csv`、0〜1）
- 副指標: 最終的な検出数（8個中）、網羅率、LLM にかかった時間
- 主な比較: 同じシード同士で `LlmGoExplore` − `UnvisitedGoExplore`、`LlmGoExplore` − `UniformGoExplore`
  - Wilcoxon 符号順位検定（両側、n=10）。有意水準 0.05。結果は差の有無にかかわらず報告する
- 10シードでは小さな差は検出できない。差が出なかった場合は「この規模で検出できる差はなかった」と報告し、追加のシードは別の計画として立てる
